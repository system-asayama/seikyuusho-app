# seikyuusho-app

請求書アプリ（Flask + PostgreSQL / Docker Compose）。
まずは管理者・利用者の2ロールによるログインシステムを実装しています。

## ログインシステムの仕様

- ロールは `admin`（管理者）と `user`（利用者）の2種類
- **最初の管理者はブートストラップ方式で登録**
  - 管理者が1人もいない状態では、どのURLにアクセスしても `/setup` に誘導される
  - `/setup` で最初の管理者のログインID・パスワードを自分で決めて登録
  - 登録後 `/setup` は自動的に無効化される（ハードコードされた初期パスワードは無し）
- **利用者は管理者だけが追加できる**（自己登録画面は無い）
  - `/admin/users` でログインID・表示名・初期パスワード・ロールを指定して追加
  - 管理者はロール変更、パスワード再設定、有効/無効の切り替え、削除ができる
  - 最後の管理者は降格・無効化・削除できない安全装置付き
  - 自分自身は無効化・削除できない
- ログインは `/login` の1画面。ロールに応じて管理者はユーザー管理、利用者はダッシュボードへ遷移
- ログイン後は `/settings` で自分の表示名・パスワードを変更できる（現在のパスワード必須）
- パスワードは8文字以上、ハッシュ化して保存。セッションベース認証
- 無効化されたアカウントはログインできず、ログイン中でも次のリクエストで弾かれる

### 自動デプロイで管理者を作りたい場合（任意）

`ADMIN_USERNAME` と `ADMIN_PASSWORD` の**両方**を環境変数で指定すると、起動時にその管理者を
自動作成します（初回セットアップ画面はスキップ）。どちらか一方でも未指定ならブートストラップ方式です。

## 起動方法

### Docker Compose

```bash
docker compose up --build
```

http://localhost:8080 にアクセスします（`WEB_PORT` でホスト側ポートを変更可）。
本番では `SECRET_KEY` を必ず変更してください。

### ローカル単体実行（SQLite にフォールバック）

`DATABASE_URL` が未設定の場合は SQLite (`instance/app.db`) を使います。

```bash
pip install -r requirements.txt
python app.py
```

### テスト

```bash
pip install pytest
pytest
```
