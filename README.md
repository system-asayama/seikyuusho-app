# seikyuusho-app

請求書作成アプリ（Flask + PostgreSQL / Docker Compose）。
管理者・利用者の2ロールでログインし、取引先ごとに請求書を作成・発行・PDF 出力できます。

## 機能

### 請求書
- 取引先を選んで請求書を作成。明細行は画面上で自由に追加・削除でき、金額はリアルタイムに集計
- 明細ごとに税率（10% / 8% 軽減 / 0%）を指定。消費税は**税率ごとに合算してから端数処理**（適格請求書の区分記載に対応）
- 端数処理（切り捨て / 四捨五入 / 切り上げ）は自社情報で設定
- 請求書番号は「プレフィックス + 西暦 + 年内連番4桁」で自動採番（手動変更も可、重複チェックあり）
- ステータス管理: 下書き → 発行済 → 入金済（入金日を記録）。入金済は編集ロック
- 一覧は状態・取引先・キーワードで絞り込み。複製して新しい請求書を作成
- **印刷用表示**（A4 レイアウト、ブラウザの「PDF として保存」対応）と **PDF ダウンロード**（reportlab、日本語フォント埋め込み）
- ダッシュボードに今月の請求額・未入金合計・支払期限超過件数・最近の請求書を表示

### 取引先
- 取引先名・敬称（御中/様）・住所・担当者・連絡先・メモを管理
- 取引先ごとの請求書一覧を表示。請求書が無い取引先だけ削除可能

### 自社情報（管理者のみ）
- 社名・住所・電話・メール・代表者・適格請求書発行事業者登録番号（T+13桁）・振込先
- 請求書の既定値: 番号プレフィックス、消費税の端数処理、支払期限の日数、備考の既定文

### ログイン / ユーザー管理
- ロールは `admin`（管理者）と `user`（利用者）の2種類
- **最初の管理者はブートストラップ方式**: 管理者が0人の間はどのURLも `/setup` に誘導され、登録後は自動的に無効化
- **利用者は管理者だけが追加**（自己登録画面は無い）。ロール変更・パスワード再設定・有効/無効・削除も管理者が行う
- 最後の管理者は降格・無効化・削除できない。自分自身は無効化・削除できない
- パスワードは8文字以上、ハッシュ化して保存。無効化されたアカウントは即座にログイン不可
- 利用者と管理者の違い: 自社情報の編集・ユーザー管理・発行済/入金済請求書の削除は管理者のみ

## 画面と URL

| URL | 内容 |
| --- | --- |
| `/setup` | 初回セットアップ（最初の管理者を登録） |
| `/login` | ログイン（管理者・利用者共通） |
| `/dashboard` | ダッシュボード |
| `/invoices` | 請求書一覧 / `/invoices/new` 作成 / `/invoices/<id>` 詳細 |
| `/invoices/<id>/print` | 印刷用表示 / `/invoices/<id>/pdf` PDF |
| `/clients` | 取引先一覧 / `/clients/new` 登録 |
| `/company` | 自社情報（管理者） |
| `/admin/users` | ユーザー管理（管理者） |
| `/settings` | 自分の表示名・パスワード変更 |

## 起動方法

### Docker Compose

```bash
docker compose up --build
```

http://localhost:8080 にアクセスします（`WEB_PORT` でホスト側ポートを変更可）。
本番では `SECRET_KEY` を必ずランダムな長い文字列に変更してください。

`ADMIN_USERNAME` と `ADMIN_PASSWORD` の**両方**を環境変数で指定すると、起動時にその管理者を
自動作成します（初回セットアップ画面はスキップ）。

### ローカル単体実行（SQLite にフォールバック）

`DATABASE_URL` が未設定の場合は SQLite (`instance/app.db`) を使います。

```bash
pip install -r requirements.txt
python app.py
```

### PDF の日本語フォント

次の順で探します。Docker イメージには IPAex ゴシックが入っています。

1. 環境変数 `PDF_FONT_PATH`（.ttf / .ttc）
2. `/usr/share/fonts` 配下の IPAex ゴシック / Noto Sans CJK
3. Windows（メイリオ・游ゴシック・MS ゴシック）/ macOS（ヒラギノ）の標準フォント
4. reportlab 内蔵の CID フォント（埋め込み無し）

### テスト

```bash
pip install pytest
pytest
```

## ファイル構成

- `app.py` — アプリ生成、認証、ユーザー管理、ダッシュボード
- `auth.py` — ログイン必須 / 管理者必須デコレータ
- `models.py` — User / CompanySetting / Client / Invoice / InvoiceItem
- `billing.py` — 金額計算・消費税集計・採番・ダッシュボード集計
- `invoices.py` / `clients.py` / `company.py` — 各画面の Blueprint
- `pdf.py` — reportlab による PDF 生成
- `templates/` — 画面テンプレート
- `test_app.py` / `test_invoices.py` — テスト
